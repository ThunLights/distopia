# Bump

`/bump` を実行するとサーバーの表示順が上がり、[distopia.top](https://distopia.top) のトップページの「新着」に表示されます。

## 使い方

1. 公開設定を済ませる(未公開のサーバーでは実行できません。[サーバー登録の仕方](/register) を参照)
2. 任意のチャンネルで `/bump` を実行する

## 制限

- 同じサーバーでは **2時間に1回** まで実行できます。
- 制限中に実行すると、あと何分で再実行できるかが表示されます。

## Bump通知

`/settings` の「Bump設定」で通知をオンにすると、Bumpの **2時間後** に実行したチャンネルへ通知が送られます。

- 通知の文面を変更できます。
- 通知時にメンションするロールを指定できます。

```text
/bump 実行
   │
   ├─ 2時間以内に実行済み → レートリミット表示(残り時間つき)
   │
   └─ 実行成功 → 表示順が上がる
                  └─ 通知オン → 2時間後に通知を送信
```

## ユーザーランキング

Bumpした回数はユーザーごとに集計され、[ランキング](https://distopia.top/ranking) の「Bump数」に表示されます。
