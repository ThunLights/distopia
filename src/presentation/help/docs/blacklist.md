# ブラックリスト

荒らしなどの対象を一覧にして、複数人で管理・共有する機能です。

## 用語

| 用語 | 意味 |
| --- | --- |
| ブラックリスト | 対象をまとめた一覧。名前とタグを持ちます |
| 対象 | 一覧に登録されたユーザー。説明を付けられます |
| 編集者 | オーナー以外で、一覧を編集できる人 |

## コマンド

| コマンド | 内容 |
| --- | --- |
| `/blacklist create` | 新しいブラックリストを作成(名前とタグを指定) |
| `/blacklist list` | 自分が所有・編集できる一覧を表示 |
| `/blacklist show` | 一覧に登録された対象を表示 |
| `/blacklist target add` / `edit` / `remove` / `manage` | 対象の追加・説明の編集・削除、メニューからの管理 |
| `/blacklist editor add` / `remove` | 編集者の追加・削除(オーナーのみ) |
| `/blacklist delete` | 一覧を削除(オーナーのみ) |

## 編集者の権限

編集者には次の権限を個別に付けられます。

- 対象の追加
- 対象の編集
- 対象の削除
- 全て

## サーバーへの適用

`/settings` の「ブラックリスト設定」で、サーバーに適用する一覧を選びます。

- BAN対象にするタグを選べます。
- 自動BANのオン/オフを切り替えられます。
- ログの送信先チャンネルを設定できます。
- 適用を解除するボタンもあります。

```text
一覧を作成 → 対象を登録 → サーバーに適用
                              │
                  参加したユーザーが一覧の対象だった場合
                              ├─ 自動BANがオン かつ 対象のタグがBAN対象タグに含まれる → BAN
                              └─ それ以外 → ログチャンネルへの通知のみ
```

::: warning 自動BANの条件
自動BANは、「自動BANがオン」で「BAN対象タグが1つ以上選ばれている」ときに、対象のタグがそのどれかに一致した場合だけ働きます。タグを選んでいないと、自動BANをオンにしてもBANされません。
:::
