# コマンド一覧

| コマンド | 内容 | 必要な権限 |
| --- | --- | --- |
| `/help` | このヘルプのURLを表示 | なし |
| `/web` | 公開設定(サーバー掲示板に載せる内容)を編集 | 管理者 |
| `/settings` | Bump・ログ・荒らし対策などの各種設定 | 管理者 |
| `/bump` | サーバーの表示順を上げる | なし |
| `/page` | このサーバーのページを表示 | なし |
| `/review submit` / `/review delete` | サーバーレビューの投稿・更新・削除 | なし(参加後90日) |
| `/friend` | フレンド募集 | なし |
| `/staff` | スタッフかどうかを確認 | なし |
| `/blacklist …` | ブラックリストの作成・管理 | 一部オーナーのみ |
| `/tts …` | 読み上げボットの操作 | なし |
| `/tts-admin …` | 読み上げボットのサーバー設定 | 管理者 |
| `/verify-admin …` | メンバー認証のサーバー設定 | 管理者 |

詳しい使い方は各ページを参照してください。

- [Bump](/bump)
- [サーバー設定](/settings)
- [メンバー認証](/verify)
- [読み上げ (TTS)](/tts)
- [ブラックリスト](/blacklist)
- [レビュー](/review)
