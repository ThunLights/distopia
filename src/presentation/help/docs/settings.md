# サーバー設定

`/settings`(管理者のみ)を実行すると設定メニューが開きます。メニューから項目を選ぶと、それぞれの設定画面に移動します。

```text
/settings
 ├─ 代理オーナー設定
 ├─ Bump設定
 ├─ 入退出メッセージ設定
 ├─ 荒らし対策設定
 ├─ ログ設定
 ├─ ホワイトリスト設定
 ├─ ブラックリスト設定  → [ブラックリスト](/blacklist)
 ├─ 統計チャンネル設定
 └─ チケット設定
```

各画面には「戻る」ボタンがあり、いつでもメニューに戻れます。

## 代理オーナー設定

サーバーのオーナー以外に、Distopia上の管理操作を任せたい人を設定します。リセットボタンで解除できます。

## Bump設定

Bump通知のオン/オフ、通知文面、メンションするロールを設定します。詳しくは [Bump](/bump) を参照してください。

## 入退出メッセージ設定

メンバーが参加・退出したときに送るメッセージの、送信先チャンネルと内容を設定します。

## 荒らし対策設定

招待リンクの投稿をブロックする設定や、ログの送信先チャンネルを設定します。

## ログ設定

ログの種類ごとに送信先チャンネルを設定します。一括で設定・解除もできます。

## ホワイトリスト設定

荒らし対策の対象外にしたい対象を登録します。

## 統計チャンネル設定

メンバー数などを表示する統計チャンネルを設定します。

- 全メンバー数 / ユーザー数 / Bot数
- アクティブレート
- アクティブレートのランキング順位

まとめて作成するボタンもあります。

## チケット設定

問い合わせ用のチケット機能を設定します。「このチャンネルにパネルを設置」で、メンバーがチケットを作成するためのパネルを投稿できます。

- カテゴリ: チケットのチャンネルを作成する場所
- 対応ロール: チケットを閲覧・対応できるロール
- ログチャンネル: 閉じたチケットの履歴を保存する場所

メンバーはパネルのボタンから件名と内容を入力してチケットを作成します。チケットは1人1件までで、作成者・対応ロール・管理者だけが閲覧できます。

閉じるとチャンネル名の先頭に `closed-` が付き、作成者と追加メンバーは見られなくなります。チャンネルは対応ロールと管理者向けに残るので、不要になったら手動で削除してください。閉じるにはボットに「ロールの管理」権限が必要です。

チケット内のボタンは、対応ロールと管理者が使えます（「チケットを閉じる」は作成者も使えます）。

- 担当する / 解除: 担当者を表示します。解除できるのは担当者本人と管理者です
- メンバー管理: 選択したメンバーをチケットに追加します。追加済みのメンバーを選ぶと削除します（ボットに「ロールの管理」権限が必要です）

::: tip 権限について
ボットに必要な権限が不足していると、一部の設定が反映されないことがあります。
:::
