# メンバー認証

参加したメンバーがボットや荒らしでないかを、Webページでの認証で確認する機能です。認証を終えたメンバーにだけロールが付与されます。

## 認証の流れ

```text
メンバーが参加
   │  (設定していれば)未認証ロールを付与
   ▼
認証案内のチャンネルにあるボタンを押す
   │
   ▼
Webの認証ページ(distopia.top/verify/…)を開く
   │
   ├─ Cloudflare Turnstile でボットでないことを確認
   ├─ (オンの場合)VPN / プロキシ / Tor 経由なら拒否
   │
   ▼
認証完了 → 認証完了ロールを付与
```

## 設定手順

すべて管理者が `/verify-admin` で行います。

| 順番 | サブコマンド | 内容 |
| --- | --- | --- |
| 1 | `channel` | 認証案内を投稿するチャンネルを設定 |
| 2 | `role` | 認証完了後に付与するロールを設定 |
| 3 | `pending-role` | 参加直後に付与する未認証ロールを設定(任意) |
| 4 | `enable` | メンバー認証を有効にする |
| 5 | `post` | 設定したチャンネルに認証案内を投稿 |

あとから `disable` で無効にできます。

## 任意の設定

- `log-channel` — 認証結果(メール・IP・VPN検知・サブ垢候補)を記録するチャンネルを設定します。個人情報を含むため、管理者だけが見られるチャンネルにしてください。
- `block-vpn` — VPN・プロキシ・Tor経由と判定された場合に認証を拒否します。

## 認証できないとき

| 表示される理由 | 対処 |
| --- | --- |
| `Used VPN` / `Used Proxy` / `Used Tor` | VPN等をオフにして再度お試しください |
| `Could not determine IP address` / `VPN check failed` | しばらくしてから再度お試しください |
| `Turnstile verification failed` | ページを再読み込みして再度お試しください |

::: warning ロールの順位
ボットのロールは、付与するロールよりも **上** に置いてください。下にあるとロールを付与できません。
:::
