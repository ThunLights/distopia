# 読み上げ (TTS)

ボイスチャンネルにボットを呼んで、テキストチャンネルの発言を読み上げます。

## 基本の使い方

1. ボイスチャンネルに参加する
2. `/tts join` を実行する(参加しているボイスチャンネルで読み上げが始まります)
3. 終わるときは `/tts leave`

## 自分の設定

| コマンド | 内容 |
| --- | --- |
| `/tts voice` | 自分の読み上げ音声を設定 |
| `/tts voice-reset` | サーバーのデフォルト音声に戻す |
| `/tts dictionary add` | 単語と読み方を登録・更新 |
| `/tts dictionary remove` | 登録した単語を削除 |
| `/tts dictionary list` | 登録した単語の一覧 |

## サーバーの設定(管理者)

`/tts-admin` で行います。

| グループ | 内容 |
| --- | --- |
| `dictionary` | サーバー全体の辞書。追加・削除・一覧に加え、ファイル(JSON / TOML)の出力と取り込みができます |
| `ignore` | 読み上げ対象外のユーザー・チャンネルの追加・削除・一覧 |
| `settings` | デフォルト音声、コマンド・URL・コードブロックを読み飛ばすか、読み上げエンジンの切り替え |

## 辞書の優先順位

```text
自分の辞書  >  サーバーの辞書
```

同じ単語がある場合は、個人の辞書が優先されます。
