# プライバシーポリシー

## 第1条 個人情報

「個人情報」とは，個人情報保護法にいう「個人情報」を指すものとし，生存する個人に関する情報であって，当該情報に含まれる氏名，生年月日，住所，電話番号，連絡先その他の記述等により特定の個人を識別できる情報及び容貌，指紋，声紋にかかるデータ，及び健康保険証の保険者番号などの当該情報単体から特定の個人を識別できる情報（個人識別情報）を指します。

## 第2条 広告等について

今後、Google Adsence等の広告掲示サービスを使うかもしれませんが、個人情報等の収集はしていません

広告等もGoogle社のアクセス情報を元に適切な広告が掲示されています。詳しくはGoogle社のホームページをご覧ください

## 第3条 メンバー認証機能で取得する情報

メンバー認証機能（導入サーバーのみ）では、認証の試行ごとに次の情報を取得します。

- DiscordのユーザーID
- Discordアカウントのメールアドレス、およびIPアドレス
- ブラウザの特徴を表す情報（フィンガープリント）とそのハッシュ値
- VPN・プロキシ・Torの利用判定結果

これらは、不正なアカウントやサブアカウントの検知、およびVPN等を利用した認証の回避防止のために利用します。

メールアドレスとIPアドレスは、認証結果のログとして、サーバー管理者が指定したDiscordのチャンネルに投稿されます。そのため、当該チャンネルを閲覧できる方には、これらの情報が表示されます。IPアドレスは本サービスのデータベースには保存しませんが、投稿されたDiscord上のメッセージはDiscord社の規約に従って保持されます。メールアドレス、フィンガープリント、VPN等の判定結果はデータベースに保存されます。

取得した情報は、法令に基づく場合を除き、上記の目的以外では利用せず、サーバー管理者以外の第三者へ提供しません。

## 第4条 登録サーバーの削除

登録サーバー等の削除依頼に関しては、Distopiaの[公式Discord](DISCORD_INVITE_LINK)にて応じるものとします。

## 第5条 プライバシーポリシーの変更

本ポリシーの内容は，法令その他本ポリシーに別段の定めのある事項を除いて，ユーザーに通知することなく，変更することができるものとします。

本サイトが別途定める場合を除いて，変更後のプライバシーポリシーは，本ウェブサイトに掲載したときから効力を生じるものとします。
